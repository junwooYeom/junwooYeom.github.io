자신의 습관을 확인하고, 알림을 받고 난 후, 그 습관에 대한 결과물을 빵으로된 아이콘으로 컬렉션을 부여해서 자신의 습관을 더욱 재밌게 가져갈 수 있는 서비스입니다.

![습관빵 소개 이미지](/assets/img/habitbread/01.png)

## ROLE

- **안드로이드 개발자**로, 초기 기획부터 전체적인 개발, 출시까지 진행하였습니다.
- **팀 서포터**로, 안드로이드 개발자 뿐만 아닌 모든 프로젝트를 진행하는 팀원분들을 전반적으로 관리하고, 팀의 관계가 원활하게 돌아갈 수 있도록 관리하였습니다.
- **UX 디자이너**로, 애플리케이션 컬렉션에 필요한 빵 아이콘을 일러스트레이터를 통하여 제작하였습니다.

## TECH

- **운영체제** : Android ( Kotlin )
- **디자인 패턴** : MVVM
- **네트워킹** : Retrofit2
- **UI** : XML with Databinding
- **비동기처리** : Kotlin Coroutine, Kotlin Flow

## EXPERIENCE

### 랭킹 기능 UI 개발

- Retrofit2 를 통하여 랭킹에 대한 정보들을 가지고 올 수 있도록 했습니다.
- XML 을 통하여 UI 를 작성하였습니다.

### 로그인 기능 개발

- Google Login 을 통해 사용자들이 로그인을 할 수 있도록 했습니다.
- Retrofit2 를 통하여 Google OAuth 를 통해 받아온 토큰을 사용하여 서버와 연동을 할 수 있도록 했습니다.

### 컬렉션 기능 UI 작업 및 개발

- Adobe Illustrator 를 통하여 빵 아이콘을 일러스트레이터를 통해 제작하였습니다.
- Retrofit2 를 이용하여 서버에 저장된 빵 아이콘을 가지고 올 수 있도록 했습니다.

### 알림 기능 개발

- FCM 을 통하여 사용자들이 작성한 알람을 정해진 시간대에 안드로이드 알림창에 보일 수 있도록 하였습니다.
