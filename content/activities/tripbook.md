자신의 여행의 대한 기록을 저장, 기록 및 다른 사람들과 공유를 할 수 있는 서비스입니다.

## ROLE

- **안드로이드 개발자**로, TripBook 애플리케이션의 전반적인 개발을 맡고 있습니다.
- **안드로이드 팀 리더**로, 다른 안드로이드 팀원들을 케어하고, 도와주고 있습니다.

## TECH

- **운영체제 :** Android ( Kotlin )
- **디자인 패턴 :** MVVM
- **네트워킹 :** Retrofit2
- **UI :** XML with Databinding
- **비동기처리 :** Kotlin Coroutine, Kotlin Flow

## EXPERIENCE

### 구조 설계

- Version Catalog 를 통하여 하나의 파일이 여러개의 모듈의 대한 버전 관리를 할 수 있도록 진행하였습니다.
- Custom Plugin Module 을 통해 여러개의 모듈에서 쓰일 수 있는 플러그인 및 Implementation 의 대한 보일러플레이트 코드를 방지합니다.

### 로그인 기능 개발

- 사용자가 직접적으로 로그인을 할 수 있도록 로그인 기능을 개발하였습니다.
- Auth0 라는 3rd party 라이브러리를 사용하여, 여러개의 플랫폼을 하나의 라이브러리로 관리할 수 있도록 하였습니다.
- Retrofit2 를 통하여 Auth0 를 통해 받아온 토큰을 서버와 로그인을 하도록 구현하였습니다.
