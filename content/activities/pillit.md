## ROLE

- **안드로이드 팀 리더**로, 전체적인 안드로이드 개발 뿐만 아닌, 같은 안드로이드 팀원들을 관리하고, 출시까지 담당하였습니다.
- **팀 서포터**로, 안드로이드 개발자 뿐만 아닌 모든 프로젝트를 진행하는 팀원분들을 전반적으로 관리하고, 팀의 관계가 원활하게 돌아갈 수 있도록 관리하였습니다.

## TECH

- **운영체제 :** Android ( Kotlin )
- **디자인 패턴 :** MVVM
- **네트워킹 :** Retrofit2
- **UI :** XML with Databinding
- **비동기처리 :** Kotlin Coroutine, Kotlin Flow

## EXPERIENCE

### 로그인 기능 개발

- Kakao SDK 를 이용하여 Kakao 에서 제공하는 AccessToken 을 받아서, 서버와의 로그인을 Kakao 토큰을 이용하여 진행할 수 있도록 개발
  - Kakao SDK, Kotlin Flow, Retrofit2
